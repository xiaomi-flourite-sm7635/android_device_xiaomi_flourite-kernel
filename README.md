# Xiaomi flourite kernel prebuilts

Stock boot artifacts and modules from **OS3.0.306.0.WPRMIXM** (Android 16).
Kernel: `6.1.138-android14-11-g0c3d559bcd85-ab14529422`.

Place at `device/xiaomi/flourite-kernel`. Keep Image, DTB, DTBO and modules
together, preserve module signatures, and use the supplied module load lists.

These are the default boot artifacts. The separate source-kernel build is
experimental and is not a drop-in replacement for this module set.
